# 東京天気サイト 仕様書

## 概要

東京の今日の天気を表示するシンプルなサイト。毎日0時・6時に自動更新する。

---

## 技術スタック

| 項目           | 内容                  |
| -------------- | --------------------- |
| フレームワーク | Next.js               |
| ホスティング   | GitHub Pages          |
| 定期実行       | GitHub Actions (cron) |
| 天気データ     | Open-Meteo API        |

---

## データ取得

### API

- **Open-Meteo API**（登録不要・無料）
- エンドポイント: `https://api.open-meteo.com/v1/forecast`
- パラメータ:
  - `latitude=35.68&longitude=139.69`（東京）
  - `hourly=temperature_2m,precipitation,weathercode`
  - `timezone=Asia%2FTokyo`

### スケジュール

- 毎日 **0時** と **6時**（JST）に GitHub Actions が自動実行
- 実行順序:
  1. `fetch-weather.ts` — Open-Meteo API から取得 → `src/data/weather.json` に保存
  2. `next build` — `weather.json` を読んで静的 HTML を `out/` に出力
  3. `npx serve out/` をバックグラウンドで起動（Playwright がアクセスするため）
  4. `generate-ogp.ts` — Playwright で `localhost:3000/ogp` をスクリーンショット → **`out/ogp.png` に直接保存**
  5. バックグラウンドのサーバーを停止
  6. GitHub Pages へデプロイ（`out/` フォルダ）

> **注意:** OGP画像（手順4）は `next build`（手順2）の後に生成する。  
> `public/ogp.png` は使わず `out/ogp.png` に直接書き込むことで、ビルドのやり直しが不要になる。

- 1時間ごとの天気表（横スクロール）

## 服装判定ロジック

### 判定基準

| 区分     | 基準気温                                     |
| -------- | -------------------------------------------- |
| **朝晩** | 7〜9時・18〜21時の気温のうち**最も低いもの** |
| **日中** | 10〜17時の気温のうち**最も高いもの**         |

### 服装テーブル

| 気温     | 服装             |
| -------- | ---------------- |
| 25°C以上 | 半袖シャツ       |
| 20〜24°C | 長袖シャツ       |
| 16〜19°C | カーディガン     |
| 12〜15°C | セーター・ニット |
| 8〜11°C  | トレンチコート   |
| 5〜7°C   | 冬物コート       |
| 4°C以下  | ダウンコート     |

## スクリプト詳細

### fetch-weather.ts

- Open-Meteo API を叩いて時間別データを取得
- `src/data/weather.json` に保存

### generate-ogp.ts

- Playwright で `localhost:3000/ogp` にアクセス
- ビューポートを 1200 × 630px に設定してスクリーンショットを撮影
- `out/ogp.png` として保存（`public/ogp.png` は使用しない）

### Next.js（next build）

- `next.config.js` に `output: 'export'` を設定することで静的 HTML を出力
- `page.tsx` がビルド時に `weather.json` を読み込み、静的ページを生成
- 出力先: `out/` ディレクトリ → GitHub Pages にデプロイ
